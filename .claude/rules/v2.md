# V2 — règles de construction

> La V2 se construit contre la spec `docs/superpowers/specs/2026-09-26-v2-socle-design.md`.

## Un chef-d'œuvre de simplicité — la règle qui passe avant les autres

Uriel, 27/09/2026 : *« Le code doit être un chef-d'œuvre de simplicité et de beauté. »*
Simple, compréhensible, propre, épuré. Pas de code compliqué, pas de tournure d'esprit bizarre.

**Comment l'appliquer, à chaque fichier :**
- **Le chemin le plus direct.** Entre deux solutions justes, la plus simple à lire gagne, même
  si l'autre est plus « maligne ». Une astuce qui demande une explication est une dette.
- **Ne pas réinventer la roue.** D'abord la plateforme (HTML, CSS, le navigateur), puis la
  bibliothèque déjà là (React Router, TanStack Query, supabase-js), en dernier du code maison.
  Exemples tenus dans le socle : le retour arrière est celui du navigateur ; le cache, celui
  de TanStack Query ; l'état d'un onglet survit parce que l'écran reste monté, pas grâce à un
  code de restauration.
- **Petit et nommé.** Une fonction fait une chose et son nom le dit. Une fonction pure dès que
  possible (`decideAccess`, `resolveTabPress`) : elle se lit et se teste seule.
- **Rien de plus que le besoin.** Pas d'option « au cas où », pas d'abstraction pour un seul
  usage. Une ligne qu'on peut retirer sans rien perdre se retire.
- **Le test de lecture.** Si Uriel, en codeur moyen, ne comprend pas un fichier en le lisant
  de haut en bas, le fichier est à réécrire — pas à commenter davantage.

## Tout est animé, fluide — dans l'UI comme dans l'UX

Uriel, 28/09/2026 : *« Toute l'application doit être animée, fluide, dans l'UI et l'UX. »*
Un changement d'état ne saute jamais : il glisse, il apparaît, il se pose.

**How to apply :**
- **Chaque changement d'état a sa transition** : ouvrir, fermer, replier, choisir, changer
  d'onglet, apparaître, disparaître. Un élément qui surgit d'un coup est un bogue d'interface.
- **Deux mouvements partagés, dans les jetons** (`tokens.css`) : `--duree-douce` /
  `--courbe-douce` pour ce qui glisse ou apparaît, `--duree-elan` / `--courbe-elan` pour un
  choix qui se pose (le curseur des Segments, l'onglet actif). Jamais une durée en dur.
- **Animer ce qui ne coûte rien** : `translate`, `opacity`, `scale`. Jamais la taille de ce
  qui est lourd à redessiner. *Le piège (28/09)* : le tiroir desktop animait la largeur de sa
  colonne, la carte se redimensionnait à chaque image et saccadait. La solution d'Uriel : la
  carte reste plein écran **sous** le tiroir, qui glisse par-dessus ; la carte écarte seulement
  ses boutons (`--decalage-carte`).
- **Une apparition s'anime aussi** : `@starting-style` pour l'état de départ d'un élément qui
  vient d'être affiché.
- **`prefers-reduced-motion` respecté partout** : les transitions tombent à zéro.
- **Vérifier dans un onglet visible** : un onglet en arrière-plan fige les transitions (et
  MapLibre ne dessine pas). Mesurer le mouvement (`getBoundingClientRect` à intervalles), pas
  seulement l'état final.

## Rien de la V1 ne rentre

Aucun import, aucun copier-coller depuis `apps/explore-web`. On relit la V1 pour comprendre
un comportement, jamais pour en reprendre le code. Les pièges des autres `.claude/rules/`
restent valables : ils sont le cahier des charges, pas du code à copier.

## Chaque fichier se lit seul

Bloc d'en-tête `QUOI / POURQUOI / (ATTENTION)` sur chaque fichier, `README.md` sur chaque
dossier. Un commentaire dans le code dit **pourquoi**, jamais ce que la ligne dit déjà.

## Le registre de purge se tient au fil de l'eau

Tout objet back croisé et douteux (RPC inutile, colonne V1, policy trop large) → une ligne dans
`docs/v2/purge-back.md`, **dans le même commit**. Pas de DROP tant que la V1 tourne.

## Tout état navigable est une URL

Un écran, une fiche, un détail ont une adresse. Le retour arrière est celui du navigateur :
jamais de pile de navigation maison, jamais de modale qui capture le bouton retour.

## Un écran n'est fini que comparé à sa maquette

**Le piège** (27/09/2026, zone Compte) : le profil fonctionnait et chaque élément était là,
mais « tout est très moche par rapport aux maquettes » (Uriel). J'avais vérifié la présence,
pas la fidélité : tailles, couleurs, alignements, fond, icônes inventés à l'œil.

**How to apply :** avant de dire qu'un écran est prêt, relever la maquette avec
`get_design_context` (valeurs exactes, icônes téléchargées dans `assets/ui/`), puis poser la
capture de la V2 à 390 px à côté de la capture Figma et reprendre chaque écart. Une couleur de
maquette absente des jetons s'ajoute à `tokens.css` (et se voit sur `/v2/da`), jamais en dur.
