Integration des Tags Colores

Comment les tags (Nature, Moyen Age, Sacre...) donnent de la couleur a la page ?

🌲 Nature 🏰 Moyen Age ⛪ Sacre

A — Pills sous la photo

Tags en badges colores entre la galerie et les thumbnails. Simple, lisible, pattern connu. Les icones SVG des tags sont affichees dans les pills.

B — Barre chromatique + liste

Barre de couleur en haut derivee des tags. Tags en liste verticale avec icone ronde. La couleur du tag principal teinte aussi le bord de l'image. Plus editorial.

Moyen Age Sacre

C — Tag dominant

Le tag principal teinte le haut de la colonne gauche (gradient subtil). Il est affiche en gros avec son icone. Les secondaires restent en petites pills. Chaque page a sa propre "couleur" selon le lieu.

Rappel : Dans la DB, chaque tag a un color, un background et un icon (SVG). Le place_type (Chateau, Eglise...) a aussi une couleur. On peut exploiter tout ca.
