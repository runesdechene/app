# lib — le calcul pur de la zone Compte

- `bio.ts` — découpe une présentation en texte, liens `https://` et mentions `@instagram`.
- `conditionTitre.ts` — la phrase qui dit comment un titre a été gagné (« Débloqué en visitant 50 lieux sur place. »).
- `distance.ts` — distance à vol d'oiseau et son écriture (« 170 km »).
