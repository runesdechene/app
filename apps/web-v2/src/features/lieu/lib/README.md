# lib — les règles pures de la fiche, sans état React

- `distance.ts` — la distance entre deux points (haversine), son libellé, la portée (200 m).
- `etatVisite.ts` — l'état du bouton de visite d'après ma position, ma dernière visite et mon souvenir.
- `souvenir.ts` — « J'y suis allé » : le geste accordé au genre, le mois (« août 2019 »), les dates possibles.
- `faits.ts` — la ligne de faits : époque, siècle, saison, accès, bivouac.
- `adresse.ts` — l'adresse courte : la rue et la commune, sans l'empilement du géocodeur.
- `phraseDePartage.ts` — la phrase de partage : le texte du Hub où {name} devient le nom du lieu, ou la
  phrase d'origine.
