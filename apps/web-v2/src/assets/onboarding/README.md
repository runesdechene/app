# assets/onboarding — les images des écrans d'entrée

Posées depuis les maquettes Figma 94:107 à 95:107, redimensionnées à leur taille d'affichage (×2)
et passées en WebP. Pour remplacer une image : écraser le fichier **sous le même nom**.

| Fichier                     | Où il s'affiche                                                       |
| --------------------------- | --------------------------------------------------------------------- |
| `photo-accueil.webp`        | premier écran : les deux voyageurs face aux montagnes (cadrée à 66 %) |
| `bord-dechire.webp`         | premier écran : la lisière déchirée du parchemin, sur le bas de photo |
| `logo-clair.webp`           | premier écran : le logo Runes de Chêne en clair, sur la photo         |
| `embleme.webp`              | Préambule : l'emblème, au-dessus du titre                             |
| `charte.webp`               | Charte : le voyageur encapuchonné                                     |
| `charte-*.svg`              | Charte : les six pictogrammes des principes (22 px)                   |
| `signer.svg`                | Charte : la coche au centre du cercle à tenir                         |
| `retour.svg`, `suivant.svg` | la flèche de retour, la flèche de « Suivant » (pochoir)               |
| `vetement.svg`              | E-mail et Nom : le vêtement (« Tu as déjà un vêtement… »)             |
| `voyageur.webp`             | Bienvenue : le voyageur sur son rocher                                |

Le fond est le parchemin des écrans (`../ui/fond-parchemin.png`), déjà là.
