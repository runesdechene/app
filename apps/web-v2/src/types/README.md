# types — les déclarations de types globales

- `css.d.ts` — les variables CSS autorisées en style inline (`--avatar`, `--nuance`, `--mesure`, `--icone`, `--nombre`, `--rang`, `--type`, `--avant`). Une variable absente d'ici est refusée par TypeScript.

On n'y range pas : les types d'une zone (ils vivent dans sa zone).
