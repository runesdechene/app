# La bascule — plan d'exécution

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** la V2 remplace la V1 à la racine d'`app.runesdechene.com` (une seule appli, Explore ;
le Campement viendra en zone à l'intérieur — décision du 07/10), sans perdre le push, les vieux
liens ni les pages SEO.

**Architecture:** deux phases. **A** — les préalables, livrés sous `/v2` pendant que la V1 tourne
(service worker maison avec push, abonnement, vieux liens, fichiers déménagés) : **faite et en
ligne en 1.6.0**. **B** — la V2 passe à la racine dans le code ; Uriel la déploie sur le site
Netlify de la V1 (`runesdechene`), qui porte le domaine. Son service worker, servi à `/sw.js` avec
la portée `/`, remplace celui de la V1 dans la même inscription et garde ses abonnements push.
La base de l'appli (`import.meta.env.BASE_URL`) passe de `/v2/` à `/`.

**Tech Stack:** React 19, React Router (data router), TanStack Query, vite-plugin-pwa
(`injectManifest`), Workbox, Supabase (RPC, edge function Deno `send-push`), Netlify.

**Spec:** `docs/superpowers/specs/2026-10-07-v2-bascule-design.md`

## Global Constraints

- pnpm uniquement ; `pnpm dlx supabase` pour la CLI Supabase. TS strict : pas de `any`,
  `@ts-ignore`, `as unknown as`. Pas de `console.log`.
- Chaque fichier : en-tête `QUOI / POURQUOI / (ATTENTION)` (`.claude/rules/v2.md`).
- Migration de la bascule : **453** (440-445 et 447-450 sont à l’autre session), `-- WHY:` en tête,
  `CREATE OR REPLACE` copié de la définition live entière ; appliquées par Uriel
  (`pnpm dlx supabase db push --linked` depuis le worktree) — le mode automatique me les refuse.
- Déploiements lancés par Uriel. Netlify : chemin absolu dans `--dir` ; la V2 se déploie **depuis
  `apps/web-v2`** pour que la CLI lise son `netlify.toml`.
- Préfixes réservés, jamais utilisés par Explore : `/campement`, `/scan`, `/lieu`, `/mouvement`,
  `/sitemap.xml`, `/sw.js`.
- Service worker : `skipWaiting` + `clientsClaim` (règle `v2.md`) ; repli de navigation en
  **liste blanche** des écrans d'Explore.
- Push : la cloche de la V2 seulement ; les types V1 sans écran V2 deviennent `silent`.
- Monter `apps/web-v2/package.json` `version` avant chaque déploiement de la V2.

## Review Focus

- Un téléphone qui avait la **V1 installée** (service worker V1 à `/`) ouvre l'appli après la
  bascule : il doit tomber sur la V2, pas sur la V1 en cache — même adresse `/sw.js`, portée `/`.
- Un **push arrivé avant** la bascule (URL V1 `/carte?placeId=…`) touché après : il doit ouvrir un
  écran V2 (`/carte?placeId=` est redirigé par Netlify ; le service worker ne réécrit rien).
- Une adresse **réservée** (`/campement/x`, `/lieu/x`) ouverte dans l'appli installée : le service
  worker ne doit pas servir Explore — test de `ecransExplore` (Task 1).
- Un joueur **sans session** qui ouvre un lien profond (`/carte/lieu/42`) : `/bienvenue`, pas une
  boucle vers la V1 disparue (Task 7).
- Un **iPhone hors appli installée** : l'abonnement push n'est pas possible — la ligne des
  Préférences doit le dire, pas échouer en silence (Task 2).

```ts
/**
 * QUOI     — ce que le service worker sert lui-même (les écrans d'Explore) et où il pose les
 *            liens d'un push (sous sa portée : /v2/ avant la bascule, / après).
 * POURQUOI — à la racine, le service worker ne doit jamais avaler un autre usage du domaine :
 *            /campement, /scan, les pages /lieu de seo-pages (spec bascule, « préfixes réservés »).
 *            Une liste blanche ne s'oublie pas quand un nouveau sous-dossier arrive.
 */
const ECRANS = ['accueil', 'carte', 'messages', 'compagnies', 'compte', 'bienvenue', 'da']

// « /accueil », « /accueil/… », ou la portée seule ; « /accueillir » n'en est pas.
export function ecransExplore(base: string): RegExp {
  return new RegExp(`^${base}(?:(?:${ECRANS.join('|')})(?:/|$)|$)`)
}

export function cheminDansLAppli(url: string, base: string): string {
  return base + url.replace(/^\//, '')
}
```

```ts
/// <reference lib="webworker" />
/**
 * QUOI     — le service worker de la V2 : précache, repli de navigation sur l'appli pour ses
 *            seuls écrans, notifications push (afficher, ouvrir le bon écran).
 * POURQUOI — spec bascule §3 : servi à /sw.js avec la portée /, il remplace celui de la V1 sur
 *            les téléphones et garde ses abonnements push.
 * ATTENTION — skipWaiting + clientsClaim : une nouvelle version prend la main tout de suite
 *            (règle v2.md, piège du 02/10).
 */
import { cleanupOutdatedCaches, matchPrecache, precacheAndRoute } from 'workbox-precaching'
import { NavigationRoute, registerRoute } from 'workbox-routing'
import { cheminDansLAppli, ecransExplore } from './sw/ecrans'

declare const self: ServiceWorkerGlobalScope

// La base de l'appli (/v2/, puis /explore/) — pas la portée du service worker, qui sera /.
const base = import.meta.env.BASE_URL

self.skipWaiting()
cleanupOutdatedCaches()
precacheAndRoute(self.__WB_MANIFEST)

// Hors des écrans d'Explore (liste blanche), la route ne s'applique pas : le réseau répond.
registerRoute(
  new NavigationRoute(
    async ({ request }) => (await matchPrecache(`${base}index.html`)) ?? fetch(request),
    { allowlist: [ecransExplore(base)] },
  ),
)

self.addEventListener('activate', (event) => {
  event.waitUntil(self.clients.claim())
})

type Push = { title?: string; body?: string; url?: string }

self.addEventListener('push', (event) => {
  let push: Push = {}
  try {
    push = (event.data?.json() ?? {}) as Push
  } catch {
    push = { body: event.data?.text() }
  }
  const url = cheminDansLAppli(push.url ?? '/accueil', base)
  event.waitUntil(
    self.registration.showNotification(push.title ?? 'Runes de Chêne', {
      body: push.body ?? '',
      icon: `${base}icon-192.png`,
      badge: `${base}icon-192.png`,
      data: { url },
      tag: url,
    }),
  )
})

self.addEventListener('notificationclick', (event) => {
  event.notification.close()
  const url = (event.notification.data as { url?: string } | null)?.url ?? base
  event.waitUntil(
    (async () => {
      const fenetres = await self.clients.matchAll({ type: 'window', includeUncontrolled: true })
      const fenetre = fenetres.find((f) => new URL(f.url).origin === self.location.origin)
      if (fenetre) {
        await fenetre.focus()
        await fenetre.navigate(url)
        return
      }
      await self.clients.openWindow(url)
    })(),
  )
})
```
